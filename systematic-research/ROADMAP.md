# Roadmap

## 0.2

- partitioned Parquet data and versioned schema catalogs;
- an event-driven engine for partial fills, limits, and multi-market calendars;
- shrinkage covariance and advanced sector/factor constraints;
- portfolio optimization with costs included in the objective;
- Python 3.13 tests and continuous performance benchmarks.

## 1.0

- stable public API;
- migration guide and deprecation policy;
- PyPI publication and hosted documentation;
- versioned public validation datasets;
- dedicated CI matrix for the `qf-rates` bridge.
